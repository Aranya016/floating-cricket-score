# Floating Cricket Score

A small live cricket score (from ESPNcricinfo) that floats on every tab.

## Install

1. Open `brave://extensions` (Chrome: `chrome://extensions`, Edge: `edge://extensions`).
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked** and choose this folder (the one with `manifest.json` in it).
4. Pin the red ball icon from the puzzle-piece menu.

Keep this folder where it is: the browser runs the extension from it.

## Using it

- The score shows as a small pill on every tab. Click it for batters, bowler and recent balls; **–** shrinks it again.
- Drag it anywhere; every tab uses the same spot.
- Click the red ball icon to pick a match or paste a Cricinfo match link.
- **Alt+Shift+C**, the **×** button, or the switch in the menu shows or hides it.
